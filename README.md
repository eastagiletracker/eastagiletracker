## East Agile Tracker

This account opens pull requests from **East Agile** — genuine
software-development contributions to a repository (a fixed bug, a failing test,
a broken build or doc), built with **agentic AI** and managed on the **East
Agile Tracker** app: a live agile board created from that repository's own
issues and pull requests.

Each pull request links the board the work was managed on. One pull request per
repository; you can merge it, close it, or ignore it.
