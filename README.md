# East Agile Tracker

[East Agile Tracker](https://eastagiletracker.com) is an agile project tracker that can be built out of a repository's own history: point it at a public GitHub repo and the issues become stories, the pull requests become labelled stories, and the milestones become epics — a working board of a project as it actually ran.

Our public work:

- [East Agile Tracker](https://eastagiletracker.com) — the tracker itself; sign in with GitHub
- [GitHub-to-EAT](https://github.com/EastAgile/GitHub-to-EAT) — MIT-licensed CLI that imports a public repository's issues into a Tracker project in one command

## About this account: agile-board

This account sends the **agile-board** pull requests: a genuine software-development contribution to a repository — a fixed bug, a repaired build, a failing test made green, a feature someone asked for — built and managed on a live board created from that repository's own history. If you received one, **[here is exactly what it is, what it changes, and how to opt out](./agile-board.md)**. The short version: at most one pull request per repository, the change is reproduced on your branch and covered by a test before it is sent, the board is built only from your repository's public issues and pull requests, and `no-more-prs` in a comment stops us for good.

The account is automated (a machine account, in GitHub's classification), operated by East Agile — a software development firm that builds, finishes, and modernises software for companies that need the engineering capacity to ship.
