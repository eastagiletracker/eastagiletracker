## East Agile Tracker

This account opens the **agile-board** pull requests: a genuine, focused
contribution to a repository — a fixed bug, a failing test, a broken build or
doc — developed and managed on a **live agile board** built from that
repository's own issues and pull requests.

Each pull request links the board it was managed on. One pull request per
repository; you can merge it, close it, or ignore it.

Operated by the **East Agile Tracker** team — [eastagiletracker.com](https://eastagiletracker.com/).
